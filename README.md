# Bike Sharing Demand Prediction

Predicting hourly bike rental demand using regression models and weather-related features.

## Overview

- Data cleaning, exploratory analysis, and visualization
- Feature engineering and regression model comparison
- Hyperparameter tuning, cross-validation, and test predictions

## Models

Linear Regression, KNN, Decision Tree, Random Forest, Extra Trees, and Gradient Boosting.

## Tech Stack

Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn

## Dataset

[Bike Sharing Demand — Kaggle](https://www.kaggle.com/competitions/bike-sharing-demand/data). `train.csv` and `test.csv` are included in the project root.

## Run

From the project folder:

```bash
pip install -r requirements.txt
jupyter notebook bikeSharingDemand.ipynb
```

Predictions are saved to `final_submission.csv` in the same folder.
